# README - Español

## Empezando con Vite + React

Este proyecto fue creado con [Vite](https://vitejs.dev/), un empaquetador de aplicaciones web moderno y rápido.

### Scripts Disponibles

En el directorio del proyecto, puedes ejecutar:

#### `npm run dev`

Ejecuta la aplicación en modo de desarrollo.
Abre [http://localhost:5173](http://localhost:5173) para verla en tu navegador.

La página se recargará automáticamente cuando hagas cambios en el código.
También podrás ver cualquier error en la consola.

#### `npm run build`

Construye la aplicación para producción en la carpeta `dist`.
Optimiza el código y genera archivos listos para desplegar en cualquier servicio de hosting estático.

#### `npm run preview`

Sirve localmente la versión optimizada de `dist` para que pruebes cómo se verá en producción.

### Aprende Más

* Documentación de React: [https://react.dev/](https://react.dev/)

# README - English

## Getting Started with Vite + React

This project was bootstrapped with [Vite](https://vitejs.dev/), a fast and modern web application bundler.

### Available Scripts

In the project directory, you can run:

#### `npm run dev`

Runs the app in development mode.
Open [http://localhost:5173](http://localhost:5173) to view it in your browser.

The page will reload automatically when you make code changes.
You may also see errors in the console.

#### `npm run build`

Builds the app for production into the `dist` folder.
It optimizes the code and generates files ready to be deployed to any static hosting service.

#### `npm run preview`

Locally serves the optimized build from `dist` so you can test how it will look in production.

### Learn More

* Vite documentation: [https://vitejs.dev/](https://vitejs.dev/)
* React documentation: [https://react.dev/](https://react.dev/)

# AGENTS.md

## Language

Reply and explain code in English, even when the prompt is in another language. That includes chat replies, plans, code explanations, comments you write, commit and pull-request text, and new entries in DECISIONS.md.

Do not answer in the prompt's language and then add an English translation.

Leave unchanged unless asked: product UI and user-facing copy, identifiers, file names, existing code and comments, and quoted tool output. Explain quotes in English.

## Project standards

Project-specific standards are not documented yet. Follow the code already in the repo. Before writing code, also read CODE_QUALITY.md, DECISIONS.md, and MCP_USAGE.md when they exist.
